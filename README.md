# DRF React Product Management

A Full Stack Product Management Application built using **Django REST Framework (DRF)** and **React.js**, with REST API integration.

## 🚀 Project Overview

This project demonstrates how to build a full-stack web application using Django REST Framework for the backend and React.js for the frontend. The frontend communicates with the backend through REST APIs to manage product data.

## 🛠️ Technologies Used

### Backend
- Python
- Django
- Django REST Framework
- SQLite (if configured as the project database)

### Frontend
- React.js
- JavaScript
- HTML5
- CSS3
- Vite

## ✨ Features

- Product management interface
- REST API integration
- Django REST Framework backend
- React.js frontend
- Product data handling
- Separate frontend and backend architecture
